Place the portal logo image here so the app can display it on the landing page.

Steps:
1. Save the image file you attached as `logo.png`.
2. Put it in this folder: `public/logo.png` (project root `public` folder).

When the dev server is running the header will load the logo from `/logo.png`.

Notes:
- Use a PNG sized to ~256x256 or similar (App will display at height 64px).
- If you prefer a different filename, update the <img src="/logo.png"> path in `src/App.jsx` accordingly.
