# ApplyNow

A minimal React + Vite scaffold for the ApplyNow project.

Getting started:

1. Install dependencies:

```powershell
npm install
```

2. Run the dev server:

```powershell
npm run dev
```

3. Open `http://localhost:3000` in your browser.

Files added:
- `src/context/FormContext.js` - form state context
- `src/components/ApplicationForm.jsx` - simple form UI
- `src/components/Header.jsx` - header
- `src/App.jsx`, `src/main.jsx` - app entry
